# v0.0.1

Release date: 2026-04-04

This is the first end-to-end live Baserow prototype checkpoint for the portable reporting middleware.

## Scope

- sample-input path works
- runtime config-check path works
- live Baserow row read works
- Baserow-to-normalized mapping works
- normalized validation works
- DRAFT-only payload generation works
- write-back to the same Baserow row works

## Release Reference

The frozen release snapshot for this version is:

- `baseline/live-baserow-success/`

That snapshot is the rollback point for the first successful live Baserow round-trip.

## Included Runtime Shape

- source adapter: Baserow prototype
- normalized schema as the internal source of truth
- sample-input test harness retained
- Baserow destination write-back fields:
  - `Workflow snapshot JSON`
  - `error message`
  - `last processed at`

## Explicit Non-Goals

- no AI generation yet
- no PDF export yet
- no OpenELIS adapter yet
- no final sign-out output

## Success Criteria Met

The prototype has proven this path:

1. real Baserow row
2. normalized internal object
3. validation
4. draft payload
5. write back to the same Baserow row

## Notes

- Baserow remains a temporary prototype adapter, not the permanent system of record.
- Future work should continue in a new working area and preserve the frozen baselines unchanged.
