# v0.0.6 AI Verification

This runbook verifies the optional OpenAI draft-section step in `working/v0.0.6-ai-draft-sections/`.

The goal is to prove three behaviors:

1. sample/direct-input mode still works safely
2. missing OpenAI config falls back cleanly to deterministic scaffold text
3. valid OpenAI config can improve draft sections without changing the rest of the workflow

## Preconditions

- Baserow access is not required for the sample-path checks below
- Node-RED is started from this repository
- use the flow file:
  - `working/v0.0.6-ai-draft-sections/reporting-flow.json`

Recommended environment:

```bash
cd /Users/varshsmac/Documents/Behring

export SOURCE_ADAPTER=baserow_prototype
export BASEROW_BASE_URL=http://localhost:8080
export BASEROW_TOKEN='replace_me_if_not_needed_for_sample'
export BASEROW_TABLE_ID=792
```

## Step 1: Import And Deploy

1. Open Node-RED at [http://127.0.0.1:1880](http://127.0.0.1:1880)
2. Import:
   - `/Users/varshsmac/Documents/Behring/working/v0.0.6-ai-draft-sections/reporting-flow.json`
3. Deploy

## Step 2: Verify Safe Fallback Without OpenAI

Unset the OpenAI variables before starting Node-RED:

```bash
unset OPENAI_API_KEY
unset OPENAI_MODEL
```

Start Node-RED:

```bash
npm run nodered
```

Then run the sample path:

```bash
curl -X POST http://127.0.0.1:1880/reporting/process-row \
  -H 'Content-Type: application/json' \
  --data @/Users/varshsmac/Documents/Behring/working/v0.0.6-ai-draft-sections/sample-input.json
```

Expected signals:

- `source_read_status = "Direct Input Ready"`
- `processing_status = "Draft Generated"`
- `destination_update_attempted = false`
- `destination_update_status = "Skipped - Direct Input Test Mode"`
- `ai_draft_sections_result.status = "Skipped - Missing OpenAI Config"`
- `ai_draft_sections_result.used_ai = false`

Expected content:

- `processing_result.normalized_workflow_result.draft_payload.draft_sections.draft_macroscopic_description` contains deterministic scaffold text
- `draft_microscopic_description` contains deterministic scaffold text
- `draft_impression` contains deterministic scaffold text

## Step 3: Enable OpenAI

Stop Node-RED and restart it with:

```bash
export OPENAI_API_KEY='replace_with_real_key'
export OPENAI_MODEL='gpt-4.1-mini'

npm run nodered
```

Run the same sample request again:

```bash
curl -X POST http://127.0.0.1:1880/reporting/process-row \
  -H 'Content-Type: application/json' \
  --data @/Users/varshsmac/Documents/Behring/working/v0.0.6-ai-draft-sections/sample-input.json
```

Expected success signals if the AI branch works:

- `ai_draft_sections_result.attempted = true`
- `ai_draft_sections_result.used_ai = true`
- `ai_draft_sections_result.response_valid = true`
- `ai_draft_sections_result.status = "Applied - OpenAI Draft Sections"`

Expected safe fallback signals if the AI branch does not work:

- `ai_draft_sections_result.attempted = true`
- `ai_draft_sections_result.used_ai = false`
- `ai_draft_sections_result.status` is one of:
  - `Fallback - OpenAI Request Failed`
  - `Fallback - Invalid AI Output`

In either fallback case:

- the workflow should still return `processing_status = "Draft Generated"`
- deterministic scaffold text should remain in the draft payload

## Step 4: Real Row Test After Sample Success

Only after the sample path behaves correctly, test one sacrificial real row:

```bash
curl -X POST http://127.0.0.1:1880/reporting/process-baserow-row-by-id \
  -H 'Content-Type: application/json' \
  -d '{"rowId":6}'
```

Expected:

- `source_read_status = "Live Read OK"`
- `processing_status = "Draft Generated"`
- `destination_update_attempted = true`
- `destination_update_ok = true`

With AI enabled and valid:

- `ai_draft_sections_result.status = "Applied - OpenAI Draft Sections"`

Then inspect the same Baserow row and confirm the `Workflow snapshot JSON` field contains improved values for:

- `draft_macroscopic_description`
- `draft_microscopic_description`
- `draft_impression`

## What Not To Expect

- no final sign-out
- no PDF generation
- no change to locked-row safeguards
- no OpenELIS integration yet

This iteration only adds optional AI enhancement to draft-only report sections.
